## 一、作業用途

本作業使用 Python 整理桌遊體驗與電影欣賞兩場活動的報名資料。

程式先將原始文字去除半形空白並統一轉成小寫，再使用 `split()` 整理成 list。list 會保留原本的重複報名資料。之後再將 list 轉成 set，去除同一場活動中的重複報名，並使用交集、聯集和差集比較兩場活動的參加者。

最後使用 dict 保存統計結果，並根據兩場活動各自去重後的人數計算應收費用。

## 二、使用的資料型別

- `tuple`：保存兩個固定的活動名稱。
- `list`：保存整理後的報名資料，保留重複項目。
- `set`：去除重複資料，以及進行交集、聯集和差集運算。
- `dict`：保存活動費用與最後的統計摘要。

## 五、個人回答

### 問題一

測試一的桌遊整理串列有 4 筆，是因為原始資料中的 Amy 出現兩次。list 會保留重複資料，所以整理後是 `['amy', 'ben', 'amy', 'cora']`。

但是收費時需要計算不同的人，因此將 list 轉成 set 後，重複的 Amy 只會留下一个，得到 3 位不同的參加者。因此桌遊費用是 3 × 120 = 360 元。

簡單來說，list 可以保留原始順序和重複資料，而 set 主要用來保留不同的資料，不適合用來保留原本的順序。

### 問題二

測試三中，桌遊與電影去重後都是 `{'amy', 'ben', 'cora'}`，所以兩場活動的交集有 3 人，聯集也只有 3 人，因此總不重複人數是 3 人。

但是報名人次要把兩場活動各自的人數相加：

3 + 3 = 6 人次。

因為 Amy、Ben、Cora 三個人都參加了兩場，所以每個人都產生兩次報名人次。

費用則分別計算：

桌遊：3 × 120 = 360 元

電影：3 × 80 = 240 元

所以總應收為：

360 + 240 = 600 元。
